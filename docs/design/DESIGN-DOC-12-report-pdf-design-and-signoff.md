# RMC Plant SaaS Software
## Design Stage Document 12: Report / PDF Design and Final Design Sign-Off Checklist

## 1. Purpose of This Document

This document defines the report, PDF, print, export, and final design sign-off requirements for the RMC Plant SaaS software.

This is the final document of the Design Stage.

It covers:

- Report categories
- Report center design
- Standard report layout
- PDF and print design
- Quotation PDF
- Order confirmation
- Batch ticket
- Delivery challan
- Weighbridge slip
- GST invoice
- Receipt
- Stock reports
- Production reports
- Dispatch reports
- Payment and outstanding reports
- Export rules
- Report security
- Final Design Stage sign-off checklist

After this document is reviewed and committed, the Design Stage can be formally closed and the project can move to the Development Stage.

---

# 3. Report Design Principles

## 3.1 Tenant-Specific Reports

Every report must be tenant-scoped.

A tenant must only see its own:

- Customers
- Orders
- Dispatches
- Invoices
- Payments
- Stock
- Reports
- Files
- Exports

---

## 3.2 Plant-Wise Reports

For multi-plant tenants, reports must support:

- All plants
- One selected plant
- Multiple selected plants if permitted

Plant access must follow `user_plant_access`.

---

## 3.5 Report Security

- Tenant

# 16. PDF and Print Design Principles

## 16.1 Tenant Branding

Every PDF must support:

- Tenant logo
- Company legal name
- GSTIN
- Address
- Contact details
- Bank details where applicable
- Authorized signature where applicable

---

## 16.2 Language Readiness

PDF templates must be Indian-language-ready.

The system must support Unicode text and future translations for:

- Labels
- Terms
- Headers
- Footers
- Status text

---

## 16.3 PDF Storage

PDFs may be generated on demand or stored.

Recommended:

```text
Generate official transaction PDFs and store copy.
Generate reports on demand unless scheduled/exported.
```

Storage path example:

```text
tenants/{tenant_id}/invoices/{invoice_id}.pdf
tenants/{tenant_id}/challans/{challan_id}.pdf
tenants/{tenant_id}/reports/{report_id}.pdf
```

---

## 16.4 PDF Security

PDF access must check:

- Tenant
- Permission
- Plant access
- Record access

Sensitive PDFs must use signed URLs.

# 31. Final Design Stage Verdict

Design Stage can be considered complete only after:

1. All 12 design outputs are committed.
2. The design consistency review is completed.
3. Owner confirms the design direction.
4. Development sequence is prepared.
5. Phase 1 sprint plan is prepared.

After sign-off, the project can move to:

```text
Development Stage
```

Correct project sequence:

```text
Idea → Requirement → Design → Development → Testing → Deployment → Training → Launch → Support
```
